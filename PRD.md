# Project PRD: Lulopop E-commerce Platform

## 1. Project Overview
**Lulopop** is a playful, vibrant e-commerce platform for a boutique boba and milk tea shop. The brand identity is built around "Boba Pop" — a design system characterized by creamy pastel colors, high-fidelity 3D character illustrations, and a friendly, rounded aesthetic. The platform serves both end-customers (ordering) and shop managers (administration).

## 2. Target Audience
- **Customers:** Boba enthusiasts, social media-savvy Gen Z and Millennials who value aesthetic presentation and seamless mobile ordering.
- **Admins:** Shop owners and baristas who need to manage inventory, track orders in real-time, and monitor business performance.

## 3. Visual Identity (Boba Pop Design System)
- **Palette:** Soft lavender (#8a76d1), matcha green, strawberry pink, and creamy off-white surfaces.
- **Typography:** Bricolage Grotesque (Bold, friendly, and modern).
- **Style:** Roundness (Full), soft shadows, and playful 3D rendered mascots for each flavor.

## 4. Feature Requirements

### 4.1. Customer Experience (Mobile & Desktop)
- **Product Discovery:** A "Flavor Inventory" grid showcasing drinks with 3D character art, pricing, and "Best Seller" or "Seasonal" tags.
- **Brand Story:** An "Our Story" page detailing the brand's mission and ingredient quality.
- **Shopping Journey:**
    - **Your Bag:** View selected items, adjust quantities, and see "Extra Joy" cross-sells.
    - **Checkout:** Two-step process for Contact and Delivery information.
    - **Payment:** Integrated Express Checkout (Apple/Google Pay) and secure card entry.
- **Order Tracking:** Post-purchase confirmation page with a live "Delivery Timeline" (Order Placed -> Brewing -> Out for Delivery -> Delivered).
- **Community:** A "Testimonies" page with a "Tidy Grid" layout for user reviews and photo sharing.

### 4.2. Admin Management (Mobile & Desktop)
- **Dashboard:** Real-time metrics for Revenue, Total Orders, Active Flavors, and Customer Satisfaction (98%).
- **Order Management:** A searchable, filterable list of all transactions with status-based color coding (Brewing, Ready, Delivered, Issue).
- **Inventory Control:** Toggle flavor availability (In Stock / Out of Stock), manage pricing, and update flavor descriptions.
- **Live Activity Feed:** Scrollable log of recent customer actions and system alerts (e.g., "Low stock alert").

## 5. Technical Requirements
- **Frontend:** Laravel Blade + Tailwind CSS.
- **Backend:** Laravel API + Laravel Breeze.
- **Device Support:** Desktop-optimized web experience and a thumb-friendly Mobile Admin/Shop interface.

## 6. Success Metrics
- **Seamless Flow:** Minimize friction from Bag to Payment.
- **Brand Cohesion:** Maintain "Boba Pop" aesthetic across both public-facing and admin-facing screens.
- **Admin Efficiency:** Quick-action tiles for common tasks (New Order, Stock, Alerts).
